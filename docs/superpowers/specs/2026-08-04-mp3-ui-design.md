# MP3 播放器 UI 设计（HTML 原型 → LVGL 迁移）

> 日期：2026-08-04
> 目标：先做 HTML 原型验证布局与交互，后续迁移 LVGL（或裸机实现）
> 约束：**无触屏**，硬件为 1 顶部按钮 + 2 右侧面按钮 + 1 右侧面编码器

## 1. 屏幕规格

- **240×320 竖屏**（ST7789 常见规格）
- HTML 原型用固定 240×320 容器模拟

## 2. 主题系统

三套预设，HTML 原型可实时切换，LVGL 迁移为颜色 token：

| 预设 | 背景 | 卡片 | 文字 | 强调 |
|---|---|---|---|---|
| **白色极简（默认）** | `#f2f3f5` | `#ffffff` 圆角+轻阴影 | `#1a1a1a` / 次级 `#8a8f99` | 主题色（待定，如蓝 `#4f8cff`） |
| 深色 hifi | `#0e1116` | `#151a22` | `#e8ecf2` | 琥珀 `#d9a441` |
| 渐变款 | 蓝紫/琥珀渐变 | 半透明白 | 白 | — |

设计语言：**卡片式**（圆角 16px、轻阴影、圆角控件），与主题无关。

## 3. 页面结构（标签页）

- **播放页**（默认页）
- **文件列表页**（SD 卡浏览，当前用模拟数据）
- **设置页**（播放模式/主题/系统信息）
- **导航页**：双击顶部按钮进入，标签页链表选择

## 4. 播放页布局（240×320）

```
┌──────────────────┐
│ ♪ 正在播放   1:23  │  ← 状态栏 24px（播放状态+当前时间）
│                  │
│   ┌──────────┐   │
│   │ 封面卡片  │   │  ← 160×160 圆角 16px 卡片（渐变/频谱占位）
│   │ 渐变/频谱 │   │     居中悬浮，轻阴影
│   └──────────┘   │
│                  │
│   歌名（22px 黑）  │  ← 长名横向滚动
│   歌手（14px 灰）  │
│ 🔊 ▓▓▓▓▓▓░░ 70% │  ← 音量条（细圆角条+图标+百分比）
│ ▓▓▓▓▓▓▓▓░░ 1:23│  ← 进度条 + 当前/总时长
│ ↻  ⏮  ⏯  ⏭    │  ← 控制区一行 4 个（模式/上首/播放/下首）
└──────────────────┘
```

## 5. 文件列表页布局

### 5.1 文件管理器模式（SD 卡浏览）

层级浏览，文件夹/文件图标区分，可进入文件夹（B 返回上级）：

```
┌──────────────────┐
│ ◀ /            (3/6)│  ← 标题栏：路径 + 位置
├──────────────────┤
│ 📁 MUSIC        › │  ← 文件夹（高亮=主题色条）
│ 📁 录音          › │
│ 🎵 花海.mp3    4:12│  ← 音频文件（歌名+时长）
│ 🎵 勾指起誓    3:03│
│ 📄 笔记.txt       │  ← 其他文件
└──────────────────┘
```

### 5.2 歌单模式（专属歌曲文件夹）

进入专属歌曲文件夹（如 `/MUSIC`）→ **歌单视图**（歌名+歌手+时长，播放器歌单风格）：

```
┌──────────────────┐
│ ◀ MUSIC 歌单  (2/8)│  ← 标题栏：文件夹名 + 歌单
├──────────────────┤
│ ▸ 歌名1   歌手1 4:12│  ← 歌单项 40px（歌名+歌手一行，右侧时长）
│   歌名2   歌手2 3:45│
│   歌名3   歌手3 3:02│
└──────────────────┘
```

- **判定：按文件夹名**（不分析内容）——文件夹名匹配歌单关键词（如 `music`/`歌曲`/`音乐`/`mp3`，可配置列表）→ 歌单模式；否则文件管理器模式
- 歌单模式下旋钮滚动选择，A 播放选中项

## 6. 设置页（简略）

列表式（同列表页布局）：播放模式 / 主题 / 系统信息 / 关于

## 7. 交互模型（核心）

### 7.1 链表导航

```
页面 = 元素链表（可聚焦元素的有序列表）
焦点索引：旋钮旋转移动（未选中元素时）
元素交互：A 键选中后，旋钮旋转操作该元素
A 键 = 选中/进入（链表深入一层）
B 键 = 退出（链表深度减一）
```

播放页链表：`[封面] [歌名] [音量条] [进度条] [模式] [上首] [播放] [下首]`

### 7.2 旋钮双模式

- **未选中元素**：旋转 = 移动焦点索引（页面元素间）
- **已选中元素**：旋转 = 操作元素（音量增减 / 进度拖动 / 模式切换）

### 7.3 Seek 确认流程（防误触）

```
焦点进度条 + A → 进入 seek 模式
→ 旋钮拖动（显示目标位置）
→ A 确认跳转 / B 取消（回到原位）
```

### 7.4 YES/NO 界面

选项放**同一侧（右缘）**，与侧键 A/B 物理位置呼应——细长小条：
**绿色=是/确认（上方，对应侧键 A）**，**红色=否/取消（下方，对应侧键 B）**

```
┌──────────────────┐
│   确定删除？       │
│                  │
│              ┌──┐│
│              │是││  ← 绿色细条（贴右缘，对应侧键 A）
│              └──┘│
│              ┌──┐│
│              │否││  ← 红色细条（贴右缘，对应侧键 B）
│              └──┘│
└──────────────────┘
```

### 7.5 硬件按键映射

| 硬件 | 播放页 | 列表页 |
|---|---|---|
| 编码器旋转 | 未选中移焦点 / 选中调值（音量、进度等） | 滚动列表（焦点移动） |
| 侧键 A | 选中元素 / 进入 | 播放选中项 |
| 侧键 B | 退出元素 / 返回 | 返回播放页 |
| 顶部按钮 | 短按=熄屏 · 双击=导航页 · 长按=开关机 | 同左 |

### 7.6 硬件物理布局

```
┌──────────────┐
│     屏幕      │
└──────────────┘   顶部按钮（顶面）
      ┌───┐
      │ A │  ← 侧键 A（右侧面上方）
      │▄▄▄│  ← 编码器（嵌入外壳只露圆弧，非表冠）
      │ B │  ← 侧键 B（右侧面下方）
      └───┘
```

## 8. HTML 原型规格

- **240×320 固定容器**居中显示，模拟屏幕（可加缩放）
- **键盘映射**：
  - `↑`/`↓` = 编码器旋转（未选中移焦点 / 选中调值）
  - `A` = 侧键 A · `S` = 侧键 B · `T` = 顶部按钮
  - 顶部按钮：短按（<300ms）= 熄屏 · 双击 = 导航页 · 长按（>2s）= 开关机
- **页面**：播放页（含 seek 模拟、播放/暂停、进度走秒）/ 文件列表页（模拟数据）/ 设置页 / 导航页
- **状态机**：播放状态（歌名/进度/音量/模式）、焦点索引、选中态、seek 模式、熄屏态
- **主题切换**：右上角小按钮循环三套预设
- 卡片风设计语言（圆角/阴影/白色极简默认）

## 9. LVGL 迁移映射（预留，后置）
